## ✨ Key Features

- 🌐 **Full Bilingual Support (PT-BR / EN):** One-click toggle switching 100% of the UI content seamlessly.
- 📱 **Mobile-First Responsive Design:** Fully responsive layout with an interactive slide-out navigation menu for mobile viewports.
- 🎨 **Executive Dark Mode Theme:** Clean UI inspired by modern developer ecosystems featuring glassmorphism accents, crisp borders, and refined micro-interactions.
- ⚡ **Dynamic Project Filtering:** Filter featured projects by category (*Full Stack*, *Backend & APIs*, *Data & Automation*).
- 📋 **Recruiter Toolkit:** Interactive modal summarizing candidate details with single-click plain text copying for ATS/recruiter databases.
- 📬 **Direct Contact Triggers:** One-click copy for email, direct WhatsApp triggers, and interactive inquiry form.

## 🚀 Getting Started Locally

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- `npm` or `yarn`

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/KaioGBaldo/meu-portfolio.git
   cd meu-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173` to view the application.

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🌐 Deployment (Vercel)

This application is configured for zero-config deployment on **Vercel**:

1. Push your changes to the `main` branch on GitHub.
2. Connect your GitHub repository to [Vercel](https://vercel.com/).
3. Vercel automatically detects Vite + React and deploys the application.
